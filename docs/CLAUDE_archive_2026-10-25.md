## 1. Goal

Learn a **phase cleaner** `f(b_dirty, mask, magnitude) -> b_clean` for single-orientation QSM (B0 ∥ z only).
It is NOT a dipole inversion. Inversion afterwards is done by the user's **eNDI with automatic stopping**
(§6), which is also the scoring method.

Premise: measured field = `D*χ + ψ` with ψ non-dipolar. Streaking comes from ψ, so remove ψ before inversion.

Honest limits (do not oversell in docs, logs or commits):
- The cone of D stays ill-posed after cleaning; eNDI's regularization/early stopping still matters.
- ψ whose spectrum is dipole-compatible cannot be separated by spectrum alone; the net needs spatial priors.
- Sim2 is ONE volume. Results on it measure fit, not generalization, until held-out data exists (§7, S2b/S4).

## 5. Method

### 5.1 Task
Input: `b_dirty = Frequency/(42.58·B0)` (ppm), plus mask and magnitude. Target: `b_clean = mask·A(Chi)` (§3.4).
The model predicts the artifact: `b_pred = mask·(b_dirty − n̂)`; last layer zero-initialized ⇒ identity at start.

### 5.2 `PhaseCleaner` (replaces `DipoleletNet`)
- Input channels: normalized `b_dirty`, `mask`, magnitude (noise-level cue; RC2 echo choice open, §10).
- Lift: 1×1×1 conv plus parallel 3/5/7 convs → C = 16–32 channels.
- N ≥ 4 residual FNO-style blocks: `v ← v + GELU( W·v + iFFT( Σ_s R_s(k)·FFT(analysis_s(v)) ) )`
  with `analysis_s` = dipolelet segment s (scale × |D| band), complex C×C mix `R_s` per segment, `W` a 1×1×1 conv skip,
  nonlinearity in image space, Hermitian projection of the spectral branch, k-conditioning
  `R_s(k)=R_s+MLP(D(k),|k|,k̂)` (weights depend on physical frequency ⇒ voxel-size agnostic).
- Add a real spatial branch with a large receptive field (e.g. a few dilated/strided 3D conv stages): since Sim2's ψ
  is mostly noise-like, spatial priors do the real work.
- Head: 1×1×1 conv → `n̂`, zero-init. No mode truncation. Gradient checkpointing per block.
- Hardware: server GPU is an RTX 5090 with 32 GB (not 96 GB), shared with the user's other jobs (~1 GB in use). Use random
  96³–128³ patches with gradient checkpointing; full-volume inference with a memory check; measure peak memory before long runs. Dev machine (Quadro P1000, 4 GB): tests at 32³–48³ on CPU only.

### 5.3 Losses (weights in TOML)
1. `L_phase`: masked L1 + L2 vs `b_clean`, normalized by `‖b_clean‖`.
2. `L_cone`: energy of `F(b_pred)` in the |D| < delta0 window, relative. Small weight (§3.3). Always log it.
3. No eNDI inside the loss (many iterations, non-smooth stopping). eNDI is evaluation-only for now; a short fixed
   unrolled differentiable inversion (a few eNDI steps, no auto-stop) is a possible later extension.

### 5.4 Training data and augmentation
- **S1/S2 (Sim2 only):** pair (`Frequency`→`mask·A(Chi)`). To avoid memorizing one noise realization, also draw
  fresh dirty inputs from the clean target with the user's complex-noise recipe: `signal = mag·exp(i·b·phs_scale) +
  (1/SNR)(randn + i·randn)`, `phase = angle(signal)/phs_scale`, using the Sim2 magnitude (SNR sampled; calibrate to
  match ψ's rms 0.0039 ppm and rough/smooth spectrum). Mix real `Frequency` and synthetic draws; report on both.
- **Later extension (§7 S4):** more volumes. Sources: RC1 (160³; COSMOS target; STI-derived fields via
  `pSTI = p33 − (p13+p23)` and real `phs_tissue`), plus phantoms built from `Segmentation.nii` with resampled per-label χ.
  Simulated artifacts per the earlier plan (noise, STI quadrupole, background remnants with imperfect removal,
  unwrapping errors) live in `src/mcno_qsm/artifacts.py`, each toggleable and seeded.
  **Note:** eNDI uses `sin(Kx − φ)`, so exact 2π unwrapping errors are invisible to the eNDI score; they only matter
  for the cleaning task itself (and for any non-sin inverter).
- Augmentation: flips along any axis and 90° in-plane rotations (z fixed ⇒ D unchanged). No arbitrary rotations.
- Separate RNG streams for simulator draws and model init.

## 6. Scoring: the user's eNDI with automatic stopping (and FANSI tools)

Files (user's, read-only; vendor unchanged copies into `external/` with SHA-256 so the server has them):
- `C:\...\QSM\Dipolelets\Dipolelets\Codes\eNDI_module_torch.py` — `ndi`, `ndi_auto`, `ndiCG`, **`ndiCG_auto`**,
  `susc2field`, `create_freqmasks_auto`, `compute_freqe_auto`. Imports `compute_xsim_torch, _build_xsim_kernels` from
  `FANSI_module_torch` (a ~2700-line file: vendor it whole, or copy those two functions verbatim with a note).
- `...\Codes\FANSI_module_torch.py` — XSIM (lines ≈1145–1227), `fansiTV`, `fansiTGV`, `WH_fansiTV`.
- `...\Codes\FANSI_tools.py` — `dipole_kernel(N, FOV)` (cornered, B0∥z), `discrete_dipole_kernel`, `imagesc3d2`,
  `compute_rmse` (NRMSE in %).

How eNDI works (read from the source): gradient descent `x ← x − τ·( Kᴴ(W·sin(Kx − φ)) − α·x )`, `W = weight²`,
**φ and x are in radians** (χ·phs_scale). `ndi_auto`/`ndiCG_auto` stop when the mean |FFT(x)| in mask m1
(|D| in 0.15–0.20, "green") exceeds that in m2 (|D| in 0.225–0.275, "cyan") after iteration 3, with both masks also
limited to a radial band set by `voxelSize` (`create_freqmasks_auto`; `voxelSize` must be a (1,3) array,
`[[dx,dy,dz]]`). Optional outputs: `rmse_history` (%, needs `chi_cosmos` and `mask`, **in the same units as x, i.e. radians**),
`xsim_history` (needs `isXSIM`, `scale` brings x to ~1 ppm range). The functions print every iteration, pick CUDA
automatically and return numpy `x` (float32).

Protocol (`src/mcno_qsm/scoring.py`, new wrapper; do not modify the user's modules):
- `phs_scale = TE·2π·42.58·B0` with TE, B0 from config (Sim2 default in the user's code: TE = 8 ms, B0 = 7 T; confirm, §10).
- Call with `input = b·phs_scale`, `K = dipole_kernel(N, N·vox)`, `weight = magnitude`, `mask`,
  `chi_cosmos = Chi·phs_scale`, `voxelSize=[[v,v,v]]`; convert the result back: `χ_ppm = x/phs_scale`. Silence the
  per-iteration prints (redirect stdout) and log iterations, time, NRMSE% and XSIM.
- Score three inputs with **identical eNDI hyperparameters** (α, τ, maxOuterIter, isPrecond — user to give them):
  (1) dirty `Frequency`, (2) cleaned output, (3) oracle `mask·A(Chi)`. (3) is the ceiling, (1) the minimum bar.
  Never tune hyperparameters per input; tune once on (1) or (3) and say which.
- Metrics: NRMSE % (masked, from eNDI/FANSI `compute_rmse` convention), XSIM, stop iteration, plus phase NRMSE,
  cone-energy fraction, per-band errors, and a streaking measure (χ̂ energy near the cone).
- The eNDI result for Sim2 `Chi` depends on `phs_scale` because of the `sin` nonlinearity (≈15 rad/ppm at TE 8 ms,
  7 T): keep TE/B0 in the saved metadata.

## 9c. Correction 2026-10-19: FANSI dipole_kernel is misaligned for odd N

`FANSI_tools.dipole_kernel` returns `fftshift(centered)`; the inverse needs `ifftshift`. Identical for even N, but for odd N
the DC zero is off index 0 (tests/test_reference_equivalence.py). Sim2 is 164x205x205 (two odd axes). Measured on RC2:
FANSI-vs-correct forward fields differ by 15.4% NRMSE (unpadded); the 256^3 padded eNDI grid is even, so eNDI itself is fine.
The same shift hits `Dipolelet.py` when `D_qsm = fftshift(dipole_kernel(odd N))` (windows 1 bin off the data spectrum).

"without k-conditioning" half of the 5,120 mixing parameters per block are inert; use real P_s there or account for it. A single shared real P_s with g = 1
reduces the block exactly to a 1x1 conv (error 1e-6).

## 9m. The brain mask is a limit of its own: TKD test on the true clean field (2026-10-21)

KEEP all S4b results of 9i-9l unchanged; this section adds a second problem on top of them (user's decision: beat the mask effect as well).
Test (`scripts/s0_tkd_mask_effect.py`, Sim2, no network, RMSE in the mask against `Chi`; also run by the user in the notebook): TKD (`|D| >= thr` inverted, the rest `sign(D)/thr`) of the
exact forward field of the ground truth. Sim2: Chi rms in the mask 0.029 ppm, outside the mask 0.004 ppm (not zero).

| threshold | whole field `D*chi`, correct kernel | `mask * D*chi`, correct kernel | `mask * D*chi`, FANSI kernel |
|---|---|---|---|
| 0.1 | 18.3% | 38.1% | 51.3% |
| 0.03 | 7.7% | 50.0% | 65.2% |
| 0.01 | 3.8% | 69.0% | 79.7% |
| 0.001 | 1.15% | 245% | 201% |
| 1e-6 | 0.65% | 1942% | 1359% |

Findings:
- With the whole field, TKD tends to the ground truth as the threshold goes to 0 (0.65%; what remains is the DC term and the exact zeros of D).
  With `mask * field` (our training target, `clean`) the error GROWS as the threshold goes to 0: the masked field is not the dipole field of any chi, so an exact inverse amplifies the inconsistency.
  The user's notebook run (masked `clean`, threshold 0.01) gave 71.5%, consistent with the 69.0% above. Not a bug in the user's code.
- Second effect: `FANSI_tools.dipole_kernel` is misaligned for odd N (Sim2 164x205x205; see 9c). Use `mcno_qsm.physics.dipole_kernel` or `np.fft.fftfreq`; do NOT use `ifftshift(FANSI kernel)` (untested and wrong for odd N).
- Consequence for the whole project: the target `mask * D*chi` (and the "oracle", eNDI 44.22%) is NOT a ceiling for the final susceptibility map. The signal outside the mask is lost to every method that uses a masked field.
  Already measured hints (9d, 9j): cleaned in mask + dirty outside is better than masked cleaned (47.74 vs 48.78 eNDI for mix; 42.43 vs 45.79 on the S2a fit, where it even beat the masked oracle 44.22).

## 9p. Option 0 built (2026-10-21): band-normalized spectral loss (user approved testing it before the U-Net options)

Closest: NeXtQSM (arXiv 2107.07752, background removal + variational inversion trained together), FINE (1905.07284, per-case fine-tuning with the physics loss), QSMnet / QSMnet+ (1803.05627, 1909.07716: L1 + gradient-difference + model loss through D), uQSM (2004.06259: complex-exponential data loss, better than linear), QSMnet-INR (2512.09425: dipole data-consistency loss weighted by exp(-|D|^2/tau^2), NRMSE 0.644 -> 0.521), LPCNN (2008.05024: 3 unrolled steps with L2 on chi only matched QSMnet, so unrolling alone gave no gain). Dipole-lets (arXiv 2510.24705): non-dipolar content sits in the near-cone bands at every scale. No QSM paper with FNOs.
- Spectral bias of FNOs (SpecBoost, 2404.07200: a second FNO on the first one's residual; PDE benchmarks only); Sobolev/H1 (2402.09084) up-weights high-k, which is mostly our noise (low value here).
- A denoiser trained with L2 that shows equal train and test error is what a posterior-mean (Bayes) floor looks like (Levin & Nadler CVPR 2011). Our own evidence: the net (26.26% phase NRMSE on Sim2) is within 0.2 points of the best LINEAR per-segment filter fitted on Sim2 (26.44%, 9m-bis): the noise family is close to its linear floor.
- Noise level: FFDNet-style conditioning. Correction to the agents: the magnitude (weight) is ALREADY an input channel; what the net does not get is the per-sample SNR (drawn in [40, 200]); an oracle test would give it sigma = 1/(SNR * magnitude).
- Task interference: all-in-one restoration papers name "negative task interference" as the limit of single networks (matches mix 49.05 vs noise 46.96); remedies: conditioning, experts/cascades (head-to-head medical evidence is thin), PCGrad (test the gradient cosine first).
- Losses: L2 for the Gaussian part (L1 gives the median), Charbonnier/Huber for the sparse part (Noise2Noise 1803.04189, Barron 1701.03077); inverse-variance weighting = magnitude^2, which is exactly the eNDI data weight W (our masked L1+L2 treats every voxel equally).
Already tested, do not repeat: a k-space/band reweighting of the loss was NEGATIVE (9p-ter, band-normalized loss); more anatomy was NULL (9ad), so "diversify anatomy" from the agents is not supported by our data. Wrap-invariant losses are not relevant in ppm fields without wraps.
Candidate plan (to be agreed with the user, each step a go/no-go): (0) diagnostics: `overfit_struct` (9ae), oracle-sigma input on the noise family, oracle Wiener floor; (1) magnitude^2-weighted field loss (matches W); (2) task loss through a differentiable unrolled eNDI (CORRECTION 2026-10-23: `ndiCG` ignores isNonlinear and ALWAYS iterates the nonlinear gradient dx = -K^H[w^2 sin(Kx - phi)] - alpha x with a Polak-Ribiere direction and a closed-form line-search step, so the unroll is nonlinear but still differentiable; the earlier 'linear' statement was wrong), against COSMOS/QSM chi, field loss kept; (3) Huber for the sparse families or a cascade; (4) SpecBoost-style second stage only if (0) shows headroom.
